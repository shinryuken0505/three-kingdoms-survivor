《三國人生錄：亂世倖存》V2.0.0-alpha.3
互動地形、戰場可讀性與立繪演出強化

【alpha.2 整合內容】
1. 河道淺水會降低一般移動速度，閃避期間不受減速影響。
2. 村落、官渡、荊州的部分農田地塊會輕度減速。
3. 洛陽、赤壁、夷陵新增餘燼危險地形視覺標記。
4. 減速與危險地形使用線條、外框與符號提示，不只依靠顏色。
5. 地形判定完全由世界座標與章節資料計算，不消耗戰鬥 RNG。
6. 新增 TerrainProfile 資料契約，作為後續 Resource 化遷移基礎。

【alpha.3 整合內容】
1. 章節開場、Boss 登場、名將候選及名將遭遇改用統一 Remaster 立繪框。
2. 立繪框依陣營顯示識別色，加入低幅度呼吸光帶與上下金屬飾線。
3. 保留目前像素戰鬥角色，不強制重繪像素人物。
4. Boss 與名將登場畫面強化視覺層級，但不改角色數值。

【實機必測】
- 第一至第三章移動、閃避及障礙碰撞。
- 河道章節減速區是否與畫面一致。
- 名將雙候選、名將遭遇與 Boss 登場立繪是否正常。
- 1280x720 下文字與立繪框是否溢出。
