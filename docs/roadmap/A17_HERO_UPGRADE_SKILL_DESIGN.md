# A17-DESIGN-012　主角升級出現名將技能之設計優化

**狀態：待處理**  
**優先度：高**  
**類型：玩法／升級池／名將系統**

## 現況問題

主角升級時可能直接出現名將技能選項，容易產生以下問題：

1. 玩家難以判斷該選項是在強化主角、主戰名將，或整體隊伍。
2. 尚未上場、位於後備或營地的名將，其主動技能若出現在一般升級池，會造成規則混亂。
3. 名將主動技能與主角 Build 技能共用同一升級池，可能稀釋近戰、弓箭、毒、召喚等核心 Build。
4. 更換主戰名將後，已取得的名將專屬升級可能失效，形成「選到廢卡」的挫折。
5. 名將特色可能被拆散成普通數值卡，降低招募、編成與羈絆的價值。

## 建議採用方向

### 核心原則：名將能力分為三層

#### 1. 主將專精（主戰名將專屬）

只有目前位於「主戰」的名將，才可在特定條件下出現其專屬強化。

- 不直接取得另一名名將的完整主動技能。
- 強化目前主戰名將既有主動技，例如：
  - 冷卻縮短
  - 範圍增加
  - 傷害或控制效果提升
  - 新增第二段效果
  - 解鎖技能分支
- 卡面明確標示「主將專精」與名將頭像。
- 當主戰名將更換時，專精資料仍綁定該名將，不會轉移給其他名將。

#### 2. 後備兵法（後備名將被動）

位於「後備」的名將不提供完整主動技能選項，而是提供較弱、可長期生效的被動能力。

範例：

- 關羽後備：近戰傷害或斬擊範圍小幅提升。
- 張飛後備：受擊後短暫擊退附近敵人，具有冷卻。
- 華佗後備：治療效果或回復品質提升。
- 諸葛亮後備：技能冷卻、控制時間或奇遇選項品質提升。

後備兵法應：

- 強度低於主戰主動技。
- 具有明確角色特色。
- 不大量佔用一般升級池。
- 可透過羈絆、名將成長或章間整備升級。

#### 3. 傳承技／通用戰法（永久解鎖後進入主角 Build）

少部分名將能力可轉化為「通用戰法」，但必須先滿足解鎖條件，例如：

- 名將羈絆達到指定等級。
- 使用該名將完成一章。
- 完成角色專屬事件。
- 圖鑑或成就解鎖。

通用戰法不是原版名將主動技能，而是抽象化後可供主角使用的 Build 元件。

範例：

- 關羽「青龍刀勢」轉化為近戰斬擊附帶弧形刀氣。
- 黃忠「百步穿楊」轉化為遠程暴擊後追加貫穿箭。
- 華佗「五禽養生」轉化為回復時獲得短暫移速或護盾。
- 諸葛亮「借東風」轉化為元素／範圍技能的冷卻聯動。

## 推薦的升級池配置

一般主角升級時，卡池建議維持：

1. **主角武器與 Build 技能**：主要來源，約 65%～75%。
2. **通用被動能力**：約 20%～25%。
3. **主將專精卡**：僅有主戰名將且符合條件時出現，約 10%～15%，每次升級最多一張。
4. **後備兵法**：原則上不進一般升級池，改由名將成長、章間整備、羈絆升級或特殊獎勵取得。
5. **傳承技**：解鎖後視為主角 Build 卡，但受武器類型與流派標籤限制。

百分比為初期測試基準，最終應由權重系統控制，不使用固定硬機率。

## Build 相容規則

- 近戰主角不應隨機出現純毒或純弓箭技能，除非本局已取得對應武器、遺物、名將傳承或流派標籤。
- 主將專精只強化目前已上場名將，不改變主角基本攻擊類型。
- 名將離開主戰後，其已取得專精保留，但暫停生效；重新編入主戰後恢復。
- 後備被動隨名將位置即時啟用或停用。
- 營地名將不提供戰鬥能力，但保留成長資料與已解鎖內容。
- 卡面必須標示來源類型：主角技能、通用被動、主將專精、傳承戰法。

## 建議資料結構

每張升級卡至少包含：

```text
id
category                  # player_skill / passive / hero_specialization / legacy_art
owner_hero_id             # 非名將卡可為空
required_roster_state     # active / reserve / any / none
required_tags
blocked_tags
build_tags
display_weight
max_level
fallback_behavior
```

名將專精資料應與名將 ID 綁定，不直接寫入主角 `skill_levels` 的一般命名空間。

## 建議流程

1. 產生主角 Build 候選。
2. 依主角武器、已取得技能與流派標籤過濾。
3. 取得目前主戰名將，產生最多一張相符的「主將專精」。
4. 依卡池權重混合候選。
5. 確保三張卡中至少兩張可直接強化目前 Build。
6. 禁止三張皆為名將、經濟或情境型卡片。
7. 玩家選擇後，依 category 寫入正確的成長資料。

## UI 建議

- 主將專精使用名將頭像、專屬邊框與「主將專精」標籤。
- 傳承戰法使用另一種邊框，避免玩家誤認為名將本人技能。
- 卡面明確顯示生效對象，例如：
  - 「關羽主戰時生效」
  - 「編入後備後生效」
  - 「主角永久取得」
- 已達上限、目前無法生效或更換名將後暫停生效的能力，需有清楚提示。

## 驗收條件

1. 一般升級池不再隨機出現未加入或位於營地名將的完整主動技能。
2. 主將專精只針對目前主戰名將出現，每次升級最多一張。
3. 主角核心 Build 不會因名將卡大量出現而難以成形。
4. 更換名將後，已取得專精不會遺失或錯套到其他名將。
5. 後備名將以被動或羈絆方式提供價值，不與主戰主動技混淆。
6. 傳承技具有明確解鎖條件與流派限制。
7. 卡面可直接辨識能力來源、生效對象及是否暫停生效。
8. 存檔與讀檔後，名將專精、傳承技與生效狀態保持正確。
9. 四語翻譯 key 完整，英文與日文卡面不破版。

## 實作順序建議

1. 盤點目前升級池中所有名將相關卡片。
2. 將現有卡片分類為主將專精、後備兵法、傳承技或應移除項目。
3. 建立升級候選過濾與權重服務。
4. 建立名將專精獨立成長資料。
5. 修改升級卡 UI 標籤與說明。
6. 加入卡池分布、自動化規則及存讀檔測試。
7. 最後才進行數值平衡。

## 初步決策

優先採用「**主戰名將專精＋後備名將被動＋少量可解鎖傳承技**」的混合方案。

不建議讓所有名將完整主動技直接混入主角一般升級池。這種作法短期看起來內容很多，實際上會稀釋 Build、破壞編成價值，也容易產生換將後的無效升級。
