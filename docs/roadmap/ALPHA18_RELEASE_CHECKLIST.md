# V2.0.0-alpha.18 封版驗收清單

## 核心流程

- 遊戲可由主選單正常開始、繼續與讀取。
- 四位主角進入戰鬥後，升級卡池會依武器類型排除明顯不相容能力。
- `level_choices` 僅保存技能 ID；完整卡片資料留在升級整合層內。
- 主將專精每次升級候選最多出現一張，且沿用既有技能 ID。
- 後備被動與傳承戰法不直接混入一般升級卡池。

## 畫面

- 升級畫面不掛載額外浮動標籤層，卡名、等級、敘述與操作提示不得重疊。
- TAB 不掛載「目前路線」與名將能力浮動面板。
- 章間整備新版視覺可正常顯示，且沿用既有輸入流程。
- 招賢館位置選擇與滿額替換資訊可辨識。
- 1280×720 下不得出現超出主要面板或覆蓋操作提示的區塊。

## 編成與存檔

- 主戰、後備、營地不得存在同一名將的重複資料。
- 招募後會補齊圖鑑、技能等級、羈絆與主動冷卻。
- 讀取舊存檔時，無效技能 ID、負等級與超過上限的等級會自動校正。
- 存檔格式維持相容，不因 Alpha.18 顯示資料增加而要求重開新檔。

## 最低人工測試

1. 刀客升級五次，不應出現投射、穿透、多射。
2. 獵戶升級五次，可正常出現投射、穿透與多射。
3. 帶兩位主戰名將升級五次，同一輪最多一張主將專精。
4. 開啟 TAB、裝備與遺物分頁，確認右側無浮動面板重疊。
5. 通關後進入章間整備，操作名將、裝備、存檔與下一章。
6. 招募名將並測試主戰滿額替換、後備滿額替換與留在營地。
7. 儲存、退出、重新讀取，確認編成與技能等級保持。

## 封版原則

Alpha.18 不再新增新的浮動 UI 層。後續資訊顯示必須內嵌既有分頁或由 `main.gd` 的正式畫面模型統一繪製，避免再次出現座標不同步與多層覆蓋。
