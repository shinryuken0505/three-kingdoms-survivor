# V2.0.0-alpha.19 目標

## 主題：戰鬥差異化與名將玩法落地

Alpha.19 不再持續堆疊浮動 UI，主要工作轉回戰鬥手感與角色差異。

### 1. 四位主角戰鬥差異化

- 刀客：近身斬擊、護甲、反擊與短距離突進。
- 獵戶：投射、穿透、多射與遠距離安全輸出。
- 毒醫：毒層數、持續傷害、回復與範圍擴散。
- 環刃：回旋投射、機動、連擊與返回路徑傷害。
- 檢查現有共用技能的實際效果，替換對該武器沒有價值的能力。

### 2. 主將專精實際效果

- 專精卡仍沿用既有技能 ID，但需加入名將來源造成的額外效果。
- 每位名將至少有一項可辨識的專精差異，而非只有卡名不同。
- 主將更換後，後續升級候選只出現目前主戰名將的專精。

### 3. 後備被動統一

- 後備名將被動改由單一計算服務整理，避免散落在戰鬥更新流程。
- 相同類型加成設定疊加上限或遞減規則。
- TAB 內嵌顯示生效中的後備效果，不使用額外浮動面板。

### 4. 戰鬥回饋與平衡

- 強化 Boss 攻速、傷害與大招預警。
- 補強張飛震波、護盾包覆、閃避冷卻顯示。
- 第三章起增加敵軍攻擊方式與兵種搭配。
- 檢查第一章弓箭手密度與分批齊射節奏。

### 5. 技術收斂

- 新 UI 必須使用既有分頁內嵌區塊或共用 Layout，不再使用絕對座標浮動覆蓋。
- 逐步將升級、編成與章間流程從 `main.gd` 拆出，但每次拆分須有回歸測試。
- 加入 1280×720、1600×900 與 1920×1080 的版位檢查規則。

## Alpha.19 驗收

1. 四位主角在前十次升級後可形成明顯不同的戰鬥體驗。
2. 主將專精不只是改名，實際效果能辨識名將特色。
3. 後備被動可在 TAB 內查看，且不與其他分頁重疊。
4. Boss 與第三章後敵軍對玩家具有足夠威脅。
5. 主要畫面在三種解析度下不出現浮動覆蓋。
