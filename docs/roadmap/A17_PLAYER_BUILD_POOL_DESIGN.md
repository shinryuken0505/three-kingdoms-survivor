# A17-DESIGN-013　主角近戰／遠戰升級路線與卡池優化

**狀態：待處理**  
**優先度：高**  
**類型：玩法／主角成長／升級池／Build**

## 目標

主角升級候選應依目前的主要攻擊方式與已形成的流派調整，避免近戰角色持續抽到純遠程能力，或遠程角色抽到只有貼身攻擊才有價值的能力。

同時保留生命、防禦、移動、拾取、經濟與通用傷害等共用升級，讓不同流派仍可自由補強生存與泛用能力。

本項與 `A17-DESIGN-012` 名將技能升級池優化共同設計：先確立主角 Build，再決定主將專精與傳承戰法是否符合該 Build。

## 核心原則

1. **不是建立完全隔離的兩套卡池**，而是使用標籤、權重與解鎖條件動態組合。
2. 每張升級卡需標示適用類型：近戰、遠戰、共用或特殊流派。
3. 主角初始武器決定初始核心標籤，但玩家取得新武器、遺物或傳承戰法後，可逐步開啟混合 Build。
4. 不相容能力原則上不出現，而不是出現後只給很低數值。
5. 每次升級至少提供兩張能直接強化目前 Build 的卡，避免三張都與現況無關。

## 建議卡池分類

### 1. 近戰專屬

適用於刀、劍、槍、拳、近距離旋斬或貼身範圍攻擊。

建議保留或新增：

- 近戰傷害
- 斬擊／揮砍範圍
- 攻擊前搖縮短
- 連斬或追加斬擊
- 擊退、破甲、處決
- 近距離命中回復
- 受擊後反擊
- 衝刺後強化下一擊
- 貼身敵人越多，獲得短暫減傷或攻速

不應預設出現：

- 純箭矢數量
- 純飛行距離
- 純投射物穿透
- 遠距離命中才生效的暴擊加成

### 2. 遠戰專屬

適用於弓、弩、飛刀、法術彈、遠距離投射物。

建議保留或新增：

- 投射物傷害
- 投射物速度
- 射程
- 穿透
- 多重射擊
- 彈射、分裂、追蹤
- 遠距離暴擊
- 命中減速或標記
- 與敵人保持距離時增加傷害

不應預設出現：

- 純揮砍範圍
- 純貼身反擊
- 只有近距離命中才觸發的能力
- 只強化刀氣以外的近戰連段

### 3. 共用能力

以下能力可保留於所有主角的升級池，但仍需控制權重與上限：

- 最大生命
- 護甲／減傷
- 移動速度
- 閃避冷卻與閃避距離
- 拾取範圍
- 經驗獲取
- 銅錢或掉落品質
- 暴擊率（若未限定攻擊類型）
- 通用傷害
- 通用攻速
- 回復、護盾與受擊無敵時間
- 名將冷卻或隊伍支援效率

共用卡不可過多，否則雖然不會出現廢卡，仍會讓武器 Build 難以成形。

### 4. 特殊流派能力

毒、火、召喚、控制、護盾、反擊等視為額外 Build 標籤。

- 初始沒有對應標籤時，只提供少量「入口卡」。
- 玩家選擇入口卡、取得相關遺物、裝備或名將傳承後，才提高該流派卡片權重。
- 已有兩級以上相關能力時，視為形成流派，可提供進階卡與終結卡。
- 不應讓近戰／遠戰判定直接封鎖元素或召喚；應由多標籤決定相容性。

## 動態標籤建議

主角當局可持有多個 Build 標籤：

```text
melee
ranged
projectile
slash
pierce
poison
fire
summon
control
shield
critical
mobility
support
```

標籤來源包括：

- 初始角色與初始武器
- 已取得技能
- 裝備與遺物
- 名將傳承戰法
- 歷史奇遇或章節獎勵

建議區分：

- `primary_tags`：目前主要武器與核心玩法，影響卡池主權重。
- `unlocked_tags`：已開啟但尚未形成的支線流派。
- `committed_tags`：已投入多次升級的成形流派，優先提供進階能力。

## 升級候選生成規則

1. 先讀取主角初始武器與目前裝備，建立主要攻擊標籤。
2. 讀取已取得技能、遺物、裝備與傳承戰法，補入已解鎖標籤。
3. 將卡片分成：核心相容、支線相容、共用、不相容。
4. 不相容卡直接排除；只有明確的流派入口卡可以例外出現。
5. 三張候選中：
   - 至少兩張為核心或已成形流派能力。
   - 最多一張為共用能力。
   - 最多一張為主將專精、傳承戰法或新流派入口。
6. 同一類純數值卡連續出現時降低權重，避免每級都只看到傷害、生命、移速。
7. 已達上限、效果無法生效或被目前武器完全淘汰的卡不得進入候選。
8. 若有效候選不足，使用相容的共用卡補位，不回退到不相容專屬卡。

## 既有能力盤點與替換原則

實作前需輸出目前所有升級卡清單，逐張標記：

```text
保留：符合目前類型且有明確用途
共用：任何類型都可使用
改為近戰：只保留於 melee／slash 類型
改為遠戰：只保留於 ranged／projectile 類型
改為入口卡：首次取得後開啟新流派
改為進階卡：已有對應能力才出現
移除或重製：數值重複、用途模糊或大多數情況無效
```

優先替換的問題卡：

- 只有特定武器可用，卻對所有角色出現的卡。
- 與另一張卡效果幾乎相同，只是數值不同的卡。
- 單純增加極小數值、選擇感很弱的卡。
- 已有更完整系統取代，例如名將完整技能混入主角卡池。
- 後期幾乎沒有價值，卻仍持續出現的低階卡。

## 建議資料欄位

每張主角升級卡至少增加：

```text
id
category
required_tags
preferred_tags
blocked_tags
granted_tags
entry_tags
minimum_tag_investment
weapon_types
weight
fallback_weight
max_level
upgrade_group
```

- `required_tags`：必須具備才能出現。
- `preferred_tags`：符合時提高權重。
- `blocked_tags`：互斥或無效時排除。
- `granted_tags`：選擇後取得的 Build 標籤。
- `entry_tags`：允許在尚未具備該流派時作為入口。
- `minimum_tag_investment`：進階卡所需的同流派投入程度。

## UI 建議

卡面顯示簡短類型標籤：

- 近戰
- 遠戰
- 共用
- 毒／火／召喚等流派
- 主將專精
- 傳承戰法

當一張卡會開啟新流派時，應顯示「開啟新路線」，不要讓玩家誤以為它是目前 Build 的直接強化。

TAB 總覽增加「當局 Build 標籤」，讓玩家知道系統目前認定的主要路線，例如：

```text
主要：近戰／斬擊
支線：暴擊／護盾
已開啟：火焰
```

## 與名將技能系統的關係

- 主將專精必須符合該名將與目前主角 Build；不必強迫完全一致，但不可產生無效效果。
- 傳承戰法視為主角卡，需遵守近戰／遠戰與流派標籤。
- 後備兵法原則上不進主角升級池。
- 名將完整主動技不再作為一般主角升級候選。

## 驗收條件

1. 近戰主角的一般升級不再出現純箭矢、多重射擊或投射物穿透，除非已開啟遠戰／投射物流派。
2. 遠戰主角不再出現純揮砍範圍、貼身反擊等無效卡，除非已取得近戰武器或混合 Build 標籤。
3. 生命、防禦、移速、拾取與其他共用能力仍可正常出現。
4. 每次三張候選至少兩張能直接強化目前 Build。
5. 新流派入口卡有明確提示，選擇後才提高後續相關卡權重。
6. 已達上限或完全無法生效的卡不再出現。
7. 主將專精與傳承戰法遵守同一套相容規則。
8. 存讀檔後，當局技能與 Build 標籤可由資料正確重建。
9. 四語卡面與 Build 標籤不破版。
10. 自動測試可驗證近戰、遠戰、混合與流派入口四種候選分布。

## 實作順序建議

1. 盤點現有升級卡與武器類型。
2. 為現有卡補上近戰、遠戰、共用與特殊流派標籤。
3. 移除或重製明顯無效、重複與低價值卡。
4. 建立 `PlayerBuildProfile`，從角色、武器、技能、裝備與遺物推導標籤。
5. 建立升級候選過濾與加權服務。
6. 接入 `A17-DESIGN-012` 的主將專精與傳承戰法。
7. 增加升級卡類型標籤與 TAB Build 摘要。
8. 進行卡池分布與實戰平衡測試。

## 初步決策

採用「**近戰／遠戰核心卡池＋共用能力＋可解鎖特殊流派**」的動態方案。

不採用固定角色只能看見單一卡池的硬切法，保留玩家透過武器、遺物與傳承戰法發展混合 Build 的空間；但在玩家尚未主動開啟支線前，不讓無關能力大量污染升級選項。
