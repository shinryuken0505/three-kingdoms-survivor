# V2.0.0-alpha.17 單次整合驗收清單

本文件供本輪整理完成後一次驗收。測試失敗時，請保留第一個 Godot 紅字與操作步驟。

## 1. 拉取與啟動

```bash
git pull origin feature/alpha17-ending
```

1. Godot 開啟專案後按 F5。
2. 主選單可操作，沒有 Parser Error。
3. Enter、Space、方向鍵與 WASD 不會一次跳兩格。

## 2. 新局與戰鬥

1. 建立新局並進入第一章。
2. 移動、攻擊、Space 閃避與 E 互動正常。
3. 遭受緩速、控制鎖定或妖煙時：
   - 主角頭上出現狀態圖示。
   - 右側 HUD 同步出現圖示。
   - 倒數正常減少，效果結束後消失。
   - 多個狀態能同時顯示。
   - 滑鼠移到右側圖示可顯示提示。

## 3. 名將整備

從行商、營地或章間開啟名將整備：

1. 上下左右可切換名將。
2. Enter／Space 開啟位置選擇。
3. 名將可移至主戰、後備與營地。
4. 已在相同位置時顯示提示，不重複加入。
5. 主戰滿額時能選擇替換對象。
6. 後備滿額時能選擇替換對象。
7. 主戰被替換名將優先進入空的後備欄；後備滿時回營地。
8. Esc 依序關閉替換畫面、位置選擇、名將整備。
9. 章間修改編成後，返回並重新讀取存檔，編成仍保留。

## 4. 招賢館

1. 招募新名將後可選主戰、後備或營地。
2. 主戰／後備滿額時進入替換流程。
3. 取消位置選擇不會修改正式編成。
4. 新名將圖鑑、技能等級、羈絆與冷卻初始化正常。

## 5. 章間整備

1. 標題、左右資訊區與底部按鈕保持置中。
2. 上一章結果、承接資源與史勢演變互不重疊。
3. 底部四個操作可循環選擇。
4. 進入名將整備後可正常返回。
5. 繼續下一章、存檔與返回主選單流程正常。
6. 960×540 或縮小視窗時，區塊與按鈕不超出畫面。

## 6. 存檔與讀取

1. 章間自動存檔提示存在。
2. 主選單的繼續遊戲／讀取存檔可使用。
3. 讀取後章節、主角、名將編成、裝備與資源正確。
4. 刪除存檔後不再顯示可繼續的舊資料。

## 7. 建議的錯誤回報格式

```text
操作位置：
操作步驟：
預期結果：
實際結果：
第一個紅字：
是否可重現：每次／偶爾
```

## 自動檢查入口

靜態檢查：

```bash
python tools/architecture_guard.py
python tools/check_localization_keys.py
python tools/check_status_effects.py
python tools/check_navigation_architecture.py
python tools/check_alpha17_integration.py
```

Godot 快速整合測試：

```bash
godot --headless --path . --script res://tests/alpha17_integration_smoke_test.gd
```

自動檢查通過不等同完整遊玩驗收，仍需依上述流程實測。
