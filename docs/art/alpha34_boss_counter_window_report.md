# Alpha.34 Boss Counter Window

- Boss recovery now opens a timed weak-point window with bonus player damage.
- Heavy bosses expose longer windows; fast bosses recover sooner.
- Damage dealt during a boss special fills a difficulty-scaled break gauge.
- Reaching the threshold cancels the remaining attack timeline and creates an extended counter window.
- Break immunity prevents permanent interruption loops.
- Dodging a timeline impact while dash invulnerability is active grants a once-per-special precision dodge reward.
- Precision dodge briefly improves movement/attack speed and reduces active hero cooldowns.

Manual QA remains required for break thresholds, feedback readability and difficulty balance.
