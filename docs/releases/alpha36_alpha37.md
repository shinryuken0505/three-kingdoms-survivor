# Alpha.36 + Alpha.37

## 陣容與招賢居
- 第一關：主將2位、後備1位。
- 第二關起：主將3位、後備2位。
- 招賢居全局上限隨開局設定為2至5次，並拉長再次出現間隔。
- 招募完成後自動開啟武將整備。

## 名將養成
- 主將取得完整戰鬥經驗。
- 後備取得45%經驗。
- 擊敗Boss提供額外經驗。
- 名將技能等級由Lv.1逐步成長至Lv.8，經驗與等級寫入章間存檔。

## 主角升級
- 去除重複選項並提高選項多樣性。
- 流派傾向只在系統內部計算，HUD不顯示流派名稱或分數。

## 戰鬥HUD
- 上方只保留關卡、時間與Boss資訊。
- 下方整合主角生命、經驗、閃避冷卻、三位主將技能、名將等級與經驗、銅錢及遺物數量。
- 遺物不再於戰鬥畫面逐一常駐顯示。
