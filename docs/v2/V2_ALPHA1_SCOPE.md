# V2.0.0-alpha.1 地貌重製與世界架構

## 本次已完成

1. 戰場底層改為世界座標繪製，不會隨主角產生貼在螢幕上的漂浮感。
2. 依 `map_shape` 建立十字街道、狹道、庭院、補給走廊、河道與長路的視覺骨架。
3. 依 `map_kind` 套用村落、都城、關隘、官渡、荊州／長坂等不同色盤與地表細節。
4. 加入農田畦線、石板接縫、泥土地表斑駁、河面細波等低成本細節。
5. 地貌繪製不消耗遊戲 RNG，避免改變敵人、掉落、名將或劇情事件機率。
6. 建立 `scripts/systems/world/world_state.gd`，作為天下大勢、勢力消長、跨局天命的後續資料契約。

## 本次刻意未做

- 尚未改變碰撞與移動速度，避免地形視覺與玩法同時大改造成回歸風險。
- 尚未批次重畫全部武將立繪；會先建立角色美術規格與分批替換流程。
- 尚未宣稱 Godot 實機通關，本環境僅能執行靜態檢查。

## Godot 實測重點

1. 各章地貌是否固定於世界座標。
2. 走到世界四周時道路、河道與背景是否斷裂或漂移。
3. 敵人、掉落與事件生成是否維持正常。
4. 低階顯示卡是否仍可穩定維持目標幀率。
