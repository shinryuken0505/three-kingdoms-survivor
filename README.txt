《三國人生錄：亂世倖存》Demo6 v0.7.9・重玩性第一階段版

【啟動方式】
1. 將整個資料夾解壓縮到新位置。
2. 先執行 Run_Diagnostics.bat。
3. 確認畫面出現 DEMO6_SELF_TEST_OK 後，再執行 開始遊戲.bat。
4. 若Godot不在預設位置，將完整EXE路徑寫入 Godot_Path.txt 第一行。

【v0.7.9主要更新】
・新增第6章「荊州風雲・新野撤軍」。
・新增第7章「長坂坡・當陽追兵」。
・新增曹仁、張郃主將與蔡瑁、夏侯恩副將，雙Boss需全部擊破才算通關。
・新增長槍兵與策士；長槍兵維持攻擊距離，策士會施放軍略與強化友軍。
・新增荊州、長坂各2組史勢奇遇，特殊選項仍只認主動名將或已啟動羈絆。
・新增兩張章節地圖與兩首章節背景音樂。
・普通攻擊音效採五聲音階輪替，形成簡短而不干擾判讀的協奏樂句。
・Boss HUD加入副將血條，主將先倒下時會等待副將結算。
・章間存檔可延續到長坂坡，舊版v3存檔仍可讀取。
